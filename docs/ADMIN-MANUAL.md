# 관리자 매뉴얼

*한국어 · [English](ADMIN-MANUAL.en.md)*

고객사에서 시스템을 운영하는 **인사담당자·시스템관리자**를 위한 문서입니다.
설치는 [INSTALL.md](../INSTALL.md)를 참고하세요.

---

## 1. 역할과 권한

| 역할 | 할 수 있는 일 |
|------|---------------|
| **시스템관리자** (admin) | 모든 기능. 브랜딩, 메뉴 권한, 코드 관리, 데이터 초기화 |
| **인사담당자** (hr_manager) | 인사·근태·휴가·급여·발령 전반. 시스템 설정은 제한 |
| **부서관리자** (dept_manager) | 조직도, 소속 직원 조회, 근태·휴가 승인 |
| **일반사원** (employee) | 본인 정보, 근태, 휴가 신청, 전자결재 |

역할별로 보이는 메뉴는 **설정 > 메뉴권한**에서 조정합니다.
설정 메뉴 자체와 감사로그는 시스템관리자만 접근하도록 두는 것을 권장합니다.

> **준비중** 배지가 붙은 메뉴(채용·교육·평가·전자계약)는 개발이 끝나지 않아 기본적으로 숨겨져 있습니다.
> 켜면 화면은 열리지만 저장이 되지 않으니 실제 업무에는 사용하지 마세요.

> 화면에서 권한을 막아도 서버에서 한 번 더 검사합니다. 예를 들어 급여 데이터는
> 인사담당자가 아니면 본인 것만 조회됩니다.

## 2. 도입 첫 주에 해야 할 일

### 2-1. 기본 정보 등록 (순서대로)

1. **설정 > 브랜딩** — 회사 로고, 시스템 이름, 브랜드 색상, 파비콘
2. **설정 > 회사정보** — 회사명, 사업자등록번호, 대표자, 주소
   → 증명서·급여명세서에 그대로 인쇄됩니다. 오타가 없는지 확인하세요.
3. **설정 > 사업장** — 사업장이 여러 곳이면 등록합니다. 사업장별로 출퇴근 시간을 다르게 둘 수 있습니다.
4. **설정 > 근무설정** — 출퇴근 시간, 주당 근로시간, 연장·야간·휴일 가산율, 지각 유예시간
5. **설정 > 휴가설정** — 연차 부여 기준(입사일/회계연도), 반차·반반차 허용 여부, 이월 정책
6. **설정 > 급여설정** — 급여일, 4대보험 요율, 비과세 한도
7. **설정 > 공휴일설정** — 해당 연도 공휴일 확인 (매년 갱신 필요)

### 2-2. 인사 데이터 올리기

**인사정보 > 데이터 가져오기** (시스템관리자 전용)

1. **엑셀 템플릿 다운로드** — 회사정보 / 부서 / 직급 / 직책 / 사원 5개 시트
2. 시트를 채웁니다.
   - **부서**: 부서코드는 영문·숫자로 짧게. 상위부서코드를 적으면 조직 계층이 만들어집니다.
   - **직급/직책**: 레벨 숫자가 낮을수록 하위입니다 (사원 1 → 대표이사 7).
   - **사원**: 사번·이름·이메일·입사일은 필수. 부서는 **부서코드**, 직급·직책은 **이름**으로 적습니다.
   - 이메일은 사원마다 달라야 합니다. 로그인 계정과 연결하는 기준이 됩니다.
3. **업로드** — 저장 전에 검증 결과를 보여줍니다. 경고가 있으면 엑셀을 고쳐 다시 올리세요.
4. **가져오기 실행**

> 같은 사번으로 다시 올리면 덮어쓰기됩니다. 수정본을 다시 올려도 중복되지 않습니다.

### 2-3. 계정 발급

임직원 계정은 데이터베이스에 직접 만들거나 시스템관리자가 발급합니다.
사원의 이메일과 계정 이메일이 같으면 자동으로 연결되어, 본인 근태·급여를 볼 수 있게 됩니다.

### 2-4. 연차 부여

**휴가관리 > 개인별 연차 현황 > 일괄 부여**
입사일 기준으로 근로기준법에 따른 연차 일수를 계산해 한 번에 부여합니다.
기존 시스템에서 이월된 잔여 연차가 있으면, 개인별로 **수동 조정**에서 사유와 함께 반영하세요.
조정 이력이 남습니다.

## 3. 매월 반복 업무

### 3-1. 근태 마감

1. **근태관리 > 근태 마감**에서 해당 월을 확인합니다.
2. 미처리 근태(퇴근 미타각, 결근)를 정리합니다.
3. **마감**을 누르면 해당 월의 근태 수정이 잠깁니다.
4. 마감 후 수정이 필요하면 **마감 해제** 후 수정하고 다시 마감합니다. 이력이 남습니다.

### 3-2. 급여 계산

1. **급여관리 > 급여 계산**
2. 연월을 고르고 **대상자 불러오기**
3. 기본급·수당이 맞는지 확인합니다.
   개인별 고정 수당은 **인사정보 > 사원 상세 > 급여** 탭에서 미리 등록해 두면 자동 반영됩니다.
4. 계산 결과에서 4대보험·소득세 공제 내역과 계산식을 확인합니다.
5. 저장 후 **급여명세서**를 출력하거나 개인별로 열람하게 합니다.

> **주의**: 소득세는 근사 계산입니다. 원천징수 신고 금액은 국세청 간이세액표로 다시 확인하세요.

### 3-3. 휴가 승인

**휴가관리 > 승인 대기**에서 처리합니다. 승인하면 연차 잔액이 자동 차감됩니다.

## 4. 수시 업무

### 인사발령 (승진·전보)

**인사발령 > 발령 등록**. 발령일을 지정하면 이력으로 남고 사원 정보에 반영됩니다.

### 증명서 발급

**인사정보 > 사원 상세 > 증명서 발급** — 재직·경력·퇴직 증명서.
회사정보와 로고가 자동으로 들어갑니다. 브라우저 인쇄로 출력하거나 PDF로 저장합니다.

### 사진·서류 등록

**사원 상세 > 사진·서류** 탭

- **증명사진**: 인사기록카드와 사원 목록에 표시됩니다 (최대 2MB)
- **첨부 서류**: 근로계약서, 주민등록등본, 자격증 사본 등 원본 PDF (최대 10MB)

> 첨부 서류는 인사담당자와 **본인만** 열람할 수 있습니다. 다른 직원은 접근할 수 없습니다.

### 퇴직 처리

**인사정보 > 퇴직 관리**에서 퇴직일과 사유를 등록하면 퇴직금이 계산됩니다.
퇴직소득세는 간이 계산이므로 실제 신고 시 재확인이 필요합니다.

### 조직 개편

**설정 > 부서관리**에서 부서를 추가·수정합니다.
없어지는 부서는 삭제 대신 **비활성**으로 두세요. 과거 이력이 부서를 참조하고 있습니다.

## 5. 매년 해야 할 일

| 시기 | 할 일 | 위치 |
|------|-------|------|
| 12월~1월 | 다음 해 공휴일 등록 | 설정 > 공휴일설정 |
| 1월 | 4대보험 요율 확인·수정 | 설정 > 급여설정 |
| 1월 | 연차 일괄 부여 | 휴가관리 > 일괄 부여 |
| 연중 | 연차 사용 촉진 알림 | 휴가관리 > 촉진알림 |

## 6. 백업

**가장 중요한 관리 업무입니다.** 사원 정보, 근태, 급여, 첨부 서류, 로고까지
모두 데이터베이스 한 곳에 있으므로 아래 한 줄이면 전체가 백업됩니다.

```bash
docker compose exec -T db pg_dump -U hrms hrms | gzip > hrms-$(date +%F).sql.gz
```

- **주 1회 이상** 실행하고, 백업 파일은 **서버와 다른 곳**에 보관하세요.
- 복원 절차는 [INSTALL.md](../INSTALL.md) 5장에 있습니다.
- 급여 계산 직전과 대규모 데이터 업로드 직전에는 반드시 백업하세요.

## 7. 보안 관리

- **최초 관리자 비밀번호를 반드시 변경**하세요. 설치 시 `.env` 파일에 평문으로 들어 있습니다.
- 퇴사자 계정은 즉시 비활성화하세요.
- **설정 > 메뉴권한**을 정기적으로 점검하세요. 급여 메뉴가 필요 없는 역할에 열려 있지 않은지 확인합니다.
- **감사로그**에서 누가 무엇을 조회·변경했는지 확인할 수 있습니다.
  보존 기간은 설정 > 감사로그설정에서 조정합니다.
- 외부에서 접속한다면 **반드시 HTTPS**를 적용하세요 (리버스 프록시).

## 8. 문제가 생겼을 때

| 증상 | 확인 |
|------|------|
| 로그인이 안 됨 | 계정이 비활성 상태인지, 비밀번호 오타인지 |
| 화면은 뜨는데 데이터가 비어 있음 | 서버 상태 `curl http://<주소>/api/health` → `database` 값 확인 |
| 특정 메뉴가 안 보임 | 설정 > 메뉴권한에서 해당 역할에 경로가 있는지 |
| 직원이 본인 급여를 못 봄 | 사원 이메일과 로그인 계정 이메일이 같은지 (연결 기준) |
| 엑셀 업로드 실패 | 검증 경고 메시지 확인. 부서코드·직급명이 시트에 있는지 |
| 연차 일수가 다름 | 설정 > 휴가설정의 부여 기준(입사일/회계연도) 확인 |
| 서비스 자체가 안 뜸 | `docker compose ps`, `docker compose logs -f app` |

해결되지 않으면 아래를 모아 공급사에 전달하세요.

```bash
docker compose logs --tail 200 app > app.log
docker compose ps > status.txt
curl -s http://localhost:3000/api/health > health.json
```

## 9. 데이터 전체 초기화

**인사정보 > 데이터 가져오기 > 전체 데이터 초기화** (시스템관리자 전용)

사원·조직·근태·휴가·급여·결재가 **모두 삭제**됩니다. 계정과 시스템 설정은 유지됩니다.
되돌릴 수 없으므로 **반드시 백업 후** 실행하고, 도입 초기 시험 데이터를 지울 때만 사용하세요.
