# 판매·납품 가이드

*한국어 · [English](SALES-DEPLOYMENT.en.md)*

영업 담당자와 납품 엔지니어를 위한 문서입니다.
기술 설치 절차는 [INSTALL.md](../INSTALL.md), 고객사 운영은
[관리자 매뉴얼](ADMIN-MANUAL.md)을 참고하세요.

---

## 1. 제품 한 줄 정의

**중소기업용 설치형 인사관리시스템.** 고객사 서버(또는 고객이 지정한 클라우드)에
설치해 인사·근태·휴가·급여·전자결재를 한 곳에서 처리합니다.
**인사 데이터가 외부로 나가지 않는 것**이 핵심 판매 포인트입니다.

## 2. 어떤 고객에게 팔 수 있는가

| 적합 | 부적합 |
|------|--------|
| 임직원 20~500명 규모 | 5명 미만 (엑셀로 충분) |
| 인사 데이터 외부 반출을 꺼리는 곳 | 그룹사 통합 인사(다중 법인 분리 필요) |
| 급여를 자체 계산하는 곳 | 급여를 전부 세무사에 위탁하고 시스템이 불필요한 곳 |
| 근태·연차 관리를 엑셀로 하는 곳 | 이미 대형 ERP(SAP·더존 등)를 쓰는 곳 |
| 사내 서버나 클라우드 계정이 있는 곳 | IT 담당자가 전혀 없고 유지보수 계약도 원치 않는 곳 |

### 경쟁 대비 강점

- **설치형** — 데이터가 고객사 서버에 남습니다. 클라우드 SaaS를 거부하는 고객에게 결정적입니다.
- **완전 화이트라벨** — 고객사 로고·시스템 이름·브랜드 색상을 설정 화면에서 바꿉니다.
  제품에 공급사 브랜드가 남지 않습니다.
- **엑셀 일괄 이관** — 기존 인사 엑셀을 템플릿에 맞춰 올리면 조직도와 사원 명부가 한 번에 들어갑니다.
- **한국 노동법 기준 내장** — 근로기준법 연차 자동 계산, 4대보험·소득세 공제, 퇴직금 정산.
- **요율 조정 가능** — 4대보험 요율·비과세 한도를 설정에서 바꿀 수 있어, 법령 개정이나
  해외 사업장(베트남 등)에도 대응합니다.

### 정직하게 말해야 할 한계

영업 중 과대 약속을 피하기 위해 알고 있어야 할 사항입니다.

- **채용·교육·평가·전자계약·연말정산·4대보험 화면은 미완성이라 기본적으로 숨겨져 있습니다.**
  고객에게는 "해당 기능은 이번 범위에 포함되지 않는다"고 안내하고, 필요하면 별도 개발 항목으로 잡으세요.
  요청이 있으면 설정 > 메뉴권한에서 켜서 보여줄 수 있으나 화면만 열릴 뿐 동작하지 않습니다.
- **급여 세액은 국세청 간이세액표가 아닌 근사 계산**입니다. 원천징수 신고 금액과 차이가 날 수 있으므로,
  급여 대장 산출용으로 안내하고 신고는 기존 절차를 유지하도록 권하세요.
- **퇴직소득세는 간이 계산**입니다. 실제 신고 세액과 다릅니다.
- **단일 법인 기준**입니다. 다중 법인을 완전히 분리하려면 설치를 분리해야 합니다.
- **HTTPS는 고객사에서 준비**해야 합니다 (리버스 프록시).

## 3. 납품 형태

### A. 온프레미스 (기본)

고객사 사내 서버 1대에 설치합니다. 인터넷 연결 없이도 동작합니다(폐쇄망 가능).

### B. 고객사 클라우드

고객 명의의 AWS/네이버클라우드 등에 동일한 방식으로 설치합니다.
데이터 소유권은 그대로 고객에게 있습니다.

> 두 경우 모두 **Docker Compose 한 번**으로 설치됩니다. 설치 시간은 30분 내외입니다.

## 4. 서버 사양 안내

| 임직원 수 | CPU | 메모리 | 디스크 |
|-----------|-----|--------|--------|
| ~100명 | 2코어 | 4GB | 20GB |
| ~300명 | 2코어 | 8GB | 50GB |
| ~500명 | 4코어 | 8GB | 100GB |

- OS: Docker가 동작하는 Linux (Ubuntu 22.04 LTS 권장)
- 디스크는 첨부 서류(계약서 PDF 등) 보관량에 좌우됩니다. 1인당 연 10MB로 잡으면 넉넉합니다.
- 별도 파일 서버·스토리지가 필요 없습니다. 사진과 서류까지 데이터베이스에 저장됩니다.

## 5. 영업 진행 순서

### 5-1. 사전 확인 체크리스트

계약 전에 고객에게 확인하세요.

- [ ] 임직원 수, 사업장 수 (사업장이 여러 곳이면 근무시간이 다른지)
- [ ] 서버를 어디에 둘 것인가 (사내 / 클라우드 / 미정)
- [ ] IT 담당자 유무, 없다면 유지보수 계약 필요
- [ ] 현재 인사 데이터 형태 (엑셀 파일이 있는지, 어떤 항목이 있는지)
- [ ] 급여를 직접 계산하는지, 세무사 위탁인지
- [ ] 근태를 어떻게 수집하는지 (지문인식기·엑셀·수기)
- [ ] 필요한 증명서 양식 (재직·경력·퇴직 외 추가 양식이 있는지)
- [ ] 도메인·HTTPS 인증서 준비 가능 여부

### 5-2. 시연

노트북 한 대로 시연할 수 있습니다. 데모 데이터(가상 직원 110명)가 포함됩니다.

```bash
npm install
npm run setup:demo     # 데모 조직까지 함께 적재
npm run build
npm run start:prod
```

`http://localhost:3000` 접속 후 `admin@example.com` / `ChangeMe123!` 로 로그인합니다.

> 시연 시에는 반드시 `start:prod`(프로덕션 모드)를 쓰세요. 개발 모드(`npm run dev`)는
> 메모리를 20배 가까이 쓰고 첫 화면이 느립니다.

**시연 추천 순서** (15분)

1. **브랜딩** — 설정 > 브랜딩에서 고객사 로고를 올리고 색상을 바꿔 보입니다.
   "저희 제품이 아니라 고객사 시스템처럼 보입니다"가 첫 인상을 만듭니다.
2. **데이터 이관** — 인사정보 > 데이터 가져오기에서 엑셀 템플릿을 보여줍니다.
   "쓰시던 엑셀을 이 양식에 맞추면 하루 만에 올라갑니다."
3. **인사카드** — 사원 상세 > 인사기록카드 인쇄 미리보기. 사진·서류 첨부 시연.
4. **연차** — 휴가관리에서 입사일 기준 자동 계산과 잔여 연차를 보입니다.
5. **급여** — 급여계산에서 4대보험·세금 공제 내역이 계산식과 함께 나오는 화면.
6. **권한** — 설정 > 메뉴권한으로 역할별로 보이는 메뉴가 달라지는 것을 보입니다.

### 5-3. 계약 시 명시할 사항

- 라이선스 범위(설치 서버 수, 임직원 수 상한)
- 데이터 소유권은 고객사에 있음
- 하자보수 기간과 유지보수 계약 조건
- 미구현 모듈(채용·교육·평가·전자계약·연말정산·4대보험)은 계약 범위 밖임을 명시
- 급여 세액이 참고용임을 명시

## 6. 납품 절차

| 단계 | 내용 | 담당 | 예상 |
|------|------|------|------|
| 1 | 서버 준비, Docker 설치 | 고객 IT / 당사 | 0.5일 |
| 2 | 설치 및 기동 ([INSTALL.md](../INSTALL.md)) | 당사 | 0.5일 |
| 3 | 브랜딩·회사정보 등록 | 당사 + 고객 | 0.5일 |
| 4 | 인사 데이터 엑셀 정리 | 고객 | 2~5일 |
| 5 | 데이터 업로드·검증 | 당사 + 고객 | 0.5일 |
| 6 | 급여 요율·근무 규정 설정 | 당사 + 고객 인사 | 0.5일 |
| 7 | 계정 발급, 권한 설정 | 고객 인사 | 0.5일 |
| 8 | 관리자 교육 ([관리자 매뉴얼](ADMIN-MANUAL.md)) | 당사 | 0.5일 |

가장 오래 걸리는 것은 **4번(고객의 엑셀 정리)** 입니다. 계약 직후 템플릿을 먼저 전달하세요.

## 8. 유지보수 항목 (연간 계약 권장)

- **법령 개정 대응** — 4대보험 요율은 매년 바뀝니다. 설정에서 고객이 직접 바꿀 수도 있지만,
  변경 안내와 확인을 서비스로 제공하면 계약 갱신 명분이 됩니다.
- **공휴일 등록** — 공휴일은 연 단위로 등록되어 있습니다. 매년 초 다음 해 공휴일 등록이 필요합니다.
- 버전 업그레이드, 장애 대응, 사용 문의

## 9. 자주 받는 질문

**Q. 데이터가 외부로 나가나요?**
아니요. 고객사 서버 안에서만 동작합니다. 인터넷이 끊겨도 사용할 수 있습니다.

**Q. 직원들이 각자 접속하나요?**
예. 역할별로 보이는 메뉴가 다릅니다. 일반 직원은 본인 정보, 근태, 휴가 신청, 결재만 봅니다.

**Q. 기존 데이터는 어떻게 옮기나요?**
엑셀 템플릿을 드립니다. 부서·직급·직책·사원을 채워 업로드하면 한 번에 등록됩니다.

**Q. 백업은 어떻게 하나요?**
명령 한 줄로 데이터베이스 전체를 파일로 받습니다. 사진과 첨부 서류까지 포함됩니다.

**Q. 서버가 고장 나면요?**
백업 파일과 이 소프트웨어만 있으면 다른 서버에 그대로 복원됩니다.

**Q. 사용자 수 제한이 있나요?**
소프트웨어 자체 제한은 없습니다. 서버 사양에 따릅니다.
